# Dictionary for learning foreign languages

## 📌 Цель проекта

Разработка системы изучения новых иностранных слов из различных иностранных языков:
- Добавление множества иностранных языков
- Реализация разделов слов по их области употребления.
- Возможность отслеживания своих результатов и просмотра уже изученных слов
- Возможность импортирования(или экспортирования) слов из приложения в отдельный файл

---

## 🧠 Основные возможности

- 🎙️ **Различные языки** — возможность изчуения слов из различных иностранных языков
- 🖥️ **Узкопрофильное изучение слов** — Изучение слов по разделам, таким как: инженерия, фильмы, искусство и др.
- 🔍 **Контроль прогресса** — постоянное наблюдение за своим прогрессом в обучении
- 📦 **Импорт/Экспорт** — возможность импортирования слов из приложения в отдельный файл и их экспортирования из него
